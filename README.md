One single joke about Monday mornings: five alarms were set, and every single one of them hit snooze on the human instead.

> I set five alarms for Monday morning. All five of them hit snooze on me.

## How it works

`main.py` (Python 3 standard library only) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
